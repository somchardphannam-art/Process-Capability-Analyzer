Important: Capability Analysis uses Normal Distribution to estimate expected performance outside specification limits. If the measurement data are not normally distributed, the calculated expected PPM / % Reject and normal-based capability interpretation may be misleading. Investigate the data distribution and consider an appropriate non-normal capability method before making decisions.

Select a worksheet column and run the Normality Test. This selector is independent of the Capability Analysis measurement column.
The test evaluates whether the sample provides sufficient evidence to reject the assumption of a normal distribution. A p-value greater than α does not prove normality.
Demo tip: Load Demo, then select Non-normal Demo (Skewed) in Column B. Its p-value is designed to be near 0.05 so you can observe how the conclusion changes with α. For Kolmogorov-Smirnov, the Lilliefors correction is applied because the normal mean and standard deviation are estimated from the sample.
Histogram + Normal Curve
Observed measurement distribution compared with a fitted normal distribution
Bars show observed frequency; the curve is fitted using the sample mean and sample standard deviation.
Normal Probability Plot (Q-Q Plot)
Observed ordered measurements versus theoretical normal quantiles
Points close to the reference line are consistent with a normal pattern; systematic curves or tail departures suggest possible non-normality.
How to select α?
0.10: More sensitive to detecting deviations from normality, with a higher Type I Error risk.
0.05: Commonly used significance level and recommended for general engineering analysis.
0.01: More conservative; stronger evidence is required to reject normality.
Select α before interpreting the result. Do not change α simply to obtain a preferred conclusion. P-Value is determined by the data; α determines the decision threshold.
